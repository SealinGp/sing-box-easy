If you are adding UI

The short version. The full checklist is §12 of DESIGN.md.

  • Density comes from tokens, never from Tailwind's global --spacing base unit. Every h-4, w-55 and max-w-* is calc(var(--spacing) * n), so retuning it would shrink every icon and the sidebar along with the padding.
  • Tables are .scroll-region + .data-table. Do not re-spell cell padding as utilities — that is how the codebase ended up with px-6 py-4 in six files and two other row heights nobody shared.
  • Radius is rounded-control / rounded-surface / rounded-pill. Never rounded-lg. Nav rows are pills; text buttons are not.
  • Elevation is shadow-surface or shadow-float. Chrome rests on the page — only genuinely floating things float.
  • Buttons are <Button>, fields are <Input>/<Textarea>, multi-value fields are <ChipsField>, dropdowns are volt/Select.
  • Before scoping any CSS under .liquid-app, check the element cannot appear inside a teleported dialog or overlay panel. That mistake has silently unstyled the entire control layer twice.
  • Dark mode is prefers-color-scheme only, and a @theme block inside a media query does not scope — Tailwind v4 hoists it to :root for every theme.
